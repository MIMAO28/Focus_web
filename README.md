《生成式人工智能应用基础二》课程作业仓库。

## 选题

**逐句精听（EchoLine）** —— 本机运行的单人听力精听训练 Web 应用（已定稿，2026-11-17）。

- 面向用户：本人，用于备考听力的精听训练；单机、单用户。
- 解决的问题：现成精听网站只能用自带材料；手动断句对轴耗时；听写结果无人批改；中断后进度丢失。
- 核心功能：导入自己的音频与原文 → 自动分句并对齐时间轴 → 逐句循环播放（上/下句、重复 3 次、倍速）→ 左侧原文、右侧听写 → 自动批改并给出错因反馈 → 进度可续。
- 技术栈：Python 3.14 + FastAPI + 原生 HTML/CSS/JS + SQLite；音频分析在浏览器端完成；分句与批改反馈调用 DeepSeek API。
- 完整需求、验收标准（AC1–AC10）、技术方案与里程碑见 [docs/requirements.md](docs/requirements.md)。
